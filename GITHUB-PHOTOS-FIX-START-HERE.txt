This package removes the assets-folder problem. Every HTML page, stylesheet,
script, photograph, logo, CNAME file, and .nojekyll file belongs at the TOP LEVEL

UPLOAD STEPS
1. Download and extract this ZIP on your computer.
2. Open the GitHub repository used for threeroots.anchorglobaltech.com.
3. Select Add file > Upload files.
4. Upload EVERY extracted item together.
5. Confirm index.html and product-supreme-clean.webp appear at the same level.
6. Commit the upload to the main branch.
7. Open Settings > Pages and choose main and /(root).
8. Wait for the deployment to finish.
9. Open https://threeroots.anchorglobaltech.com and press Ctrl+F5.
